# sales-performance-dashboard

An interactive **Sales Performance Dashboard** built to analyze sales metrics, geographic trends, and overall business performance. This dashboard provides a clear view of key performance indicators (KPIs), monthly sales trends, and top-performing product sub-categories.

---

## 🚀 Key Features & Metrics

### 📌 Core KPIs
* **Sum of Sales:** 49,096 (Total revenue generated)
* **Sum of Profit:** 16,250 (Total net profit)
* **Sum of Quantity:** 705 units sold
* **Sum of Discount:** 0 (Total discount applied)
* **No. of Customers:** 83 unique customers

### 🎛️ Interactive Filters & Slicers
* **Time & Segment Slicers:** Filter data dynamically by **Year**, **Month**, **Segment**, and **Quarter**.
* **Date Range Selector:** Analyze historical data ranging from **03-01-2016 to 30-12-2019**.
* **State Selection Panel:** Quick-filter sales performance across specific US states (e.g., Alabama, California, Florida, Georgia, etc.).

### 📈 Visualizations
* **Sum of Sales by Location (Map):** Geographic distribution highlighting regional sales performance.
* **Sum of Sales by Month (Sales Trend):** Line chart tracking monthly revenue fluctuations from January to December.
* **Sum of Top 5 Sales by Sub-Category:** Funnel/bar chart showcasing top revenue-generating sub-categories (**Binders**, **Storage**, **Phones**, **Bookcases**, and **Accessories**).

---

## 🛠️ Tools & Technologies Used
* **BI Tool:** Microsoft Power BI
* **Data Source:** Retail Sales Dataset (Excel / CSV)
* **Visuals:** KPI Cards, Filled/Bubble Map, Line Chart, Funnel/Bar Chart, Slicers

## ⚙️ How to Use
1. Clone or download this repository to your local machine.
2. Open the `.pbix` file using **Microsoft Power BI Desktop**.
3. If prompted, update the data source path to point to your local dataset file and click **Refresh**.
4. Use the top slicers and left state panel to explore insights interactively.
